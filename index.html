Projects

Real-Time Predictive Maintenance Model

This project leverages Edge Computing and Digital Twin technology to create a real-time predictive maintenance solution for washing machines. The goal is to address unscheduled breakdowns, costly repairs, and prolonged downtime.

The strategy aims to improve operational performance by making washing machines more reliable and efficient. Digital Twin technology mimics machine operation, enabling continuous monitoring and analysis to predict issues before they occur.

Edge computing enhances the Digital Twin by providing quicker analysis on edge devices, reducing dependency on cloud infrastructure and enabling real-time decision-making.

This project aligns with the emerging field of smart technologies, contributing to smarter, more efficient household appliances and promoting sustainability.

Face Detector for Attendance System

This project focuses on designing a face detection system for an attendance management application. The system uses a camera to detect faces in real-time. When a face is detected, the indicator turns red, signaling successful recognition; when no face is present, it turns blue. This color-coded feedback simplifies attendance marking, providing visual confirmation.

The system integrates computer vision algorithms such as Haar cascades or deep learning-based facial recognition models with hardware for real-time feedback. Face detection is the process of identifying and locating human faces in images or video frames, forming a key step in facial recognition. Algorithms like the Viola-Jones face detector and Convolutional Neural Networks (CNNs) are employed to identify facial features such as eyes and nose.

Detected face coordinates are used to activate the color indicators, enhancing the user experience and ensuring an efficient, accurate attendance management process.
